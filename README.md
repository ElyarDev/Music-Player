# 🎵 Music Player

A simple and responsive music player built with HTML, CSS, and JavaScript. Play your favorite songs with playback controls and customizable audio settings.

## 🔗 Live Demo
[View Music Player](https://elyardev.github.io/Music-Player/)

## ✨ Features
- ▶️ Play and pause music
- ⏭️ Next and previous track
- 🎧 Song title, artist, and cover display
- 📊 Interactive progress bar with current time and duration
- 🔊 Adjustable volume
- ⏩ Playback speed control
- 🔄 Automatic next song playback

## 🛠️ Built With
- HTML5
- CSS4
- JavaScript
- Remix Icon

## 🚀 Getting Started
1. Clone this repository.
2. Open `index.html` in your browser.
3. Add your audio files to `assets/audio/`.
